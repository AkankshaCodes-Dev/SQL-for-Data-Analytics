## 1. What are Multiple-table JOINs?

Multiple-table JOINs are used to combine data from three or more tables using related columns.

In real-world databases, information is usually stored in separate tables to avoid unnecessary duplication.

For example:
- Customers — customer information.
- Orders — customer order information.
- Products — product information.
- OrderDetails — products included in each order.

## 3. Understanding JOIN Keys

JOIN keys are common columns used to connect related tables.

| Tables | Common Column |
|---|---|
| Customers + Orders | CustomerID |
| Orders + OrderDetails | OrderID |
| OrderDetails + Products | ProductID |

Choosing the correct JOIN keys is important because incorrect matching can produce inaccurate results.

## 4. Multiple-table JOIN Syntax

```sql
SELECT columns
FROM Table1
INNER JOIN Table2
ON Table1.common_column = Table2.common_column
INNER JOIN Table3
ON Table2.common_column = Table3.common_column;
```

Additional JOIN statements can be used to connect more tables.

## 5. Practical Example — Join Four Tables

Display customer names, order IDs, product names and quantities.

```sql
SELECT
    Customers.CustomerName,
    Orders.OrderID,
    Products.ProductName,
    OrderDetails.Quantity
FROM Customers
INNER JOIN Orders
ON Customers.CustomerID = Orders.CustomerID
INNER JOIN OrderDetails
ON Orders.OrderID = OrderDetails.OrderID
INNER JOIN Products
ON OrderDetails.ProductID = Products.ProductID;
```

### Expected Output

| CustomerName | OrderID | ProductName | Quantity |
|---|---:|---|---:|
| Akash | 201 | Laptop | 1 |
| Akash | 201 | Mouse | 2 |
| Priya | 202 | Keyboard | 1 |
| Akash | 203 | Mouse | 3 |

## 6. Calculate Total Sales by Customer

Sales are calculated using:

**Sales = Quantity × UnitPrice**

```sql
SELECT
    Customers.CustomerName,
    SUM(OrderDetails.Quantity * OrderDetails.UnitPrice)
        AS TotalSales
FROM Customers
INNER JOIN Orders
ON Customers.CustomerID = Orders.CustomerID
INNER JOIN OrderDetails
ON Orders.OrderID = OrderDetails.OrderID
GROUP BY Customers.CustomerName;
```

### Expected Output

| CustomerName | TotalSales |
|---|---:|
| Akash | 42500 |
| Priya | 1000 |

**Explanation:**

Akash:
- Laptop: 1 × 40000 = 40000
- Mouse: 2 × 500 = 1000
- Mouse: 3 × 500 = 1500
- Total Sales = 42500

Priya:
- Keyboard: 1 × 1000 = 1000

## 7. Calculate Total Sales by Product

```sql
SELECT
    Products.ProductName,
    SUM(OrderDetails.Quantity * OrderDetails.UnitPrice)
        AS TotalSales
FROM Products
INNER JOIN OrderDetails
ON Products.ProductID = OrderDetails.ProductID
GROUP BY Products.ProductName;
```

### Expected Output

| ProductName | TotalSales |
|---|---:|
| Laptop | 40000 |
| Mouse | 2500 |
| Keyboard | 1000 |

## 8. Calculate Total Quantity Sold by Product

```sql
SELECT
    Products.ProductName,
    SUM(OrderDetails.Quantity) AS TotalQuantity
FROM Products
INNER JOIN OrderDetails
ON Products.ProductID = OrderDetails.ProductID
GROUP BY Products.ProductName;
```

### Expected Output

| ProductName | TotalQuantity |
|---|---:|
| Laptop | 1 |
| Mouse | 5 |
| Keyboard | 1 |

# 11. Key Takeaways

- Multiple-table JOINs combine information from three or more tables.
- JOIN keys connect related tables.
- ON specifies the matching condition.
- GROUP BY groups records based on a column.
- SUM() calculates total values.
- Quantity × UnitPrice calculates sales revenue.
- Multiple-table JOINs are useful for customer analysis, product analysis and business reporting.
